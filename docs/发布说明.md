# EvoFlow 3.0.1.5 发布说明

> 本版本已完成 Windows 全量回归、发布接口及 Ubuntu WSL 构建与便携接口验证。

EvoFlow 是面向组合优化与连续优化的 C++17 演化计算平台。本版本提供命令行程序、浏览器式本地界面、Python 接口、算法与问题配置、结果分析和外部 benchmark 接入示例。

## 交付平台

- Windows x64：提供静态运行时构建的 `evoflow.exe`。
- Python：提供 Windows x64、64 位 CPython 3.8、3.9、3.10、3.11、3.12 对应的五个扩展模块；解释器会按 ABI 标签选择匹配文件。
- Linux：支持从源码构建核心库、CLI 和 Python 扩展；已在 Ubuntu 24.04 x86_64 环境验证。不提供 Linux 预编译包，图形界面与模型连接也不作 Linux 支持承诺。
- macOS：本版本未验证，不作支持承诺。

Python 扩展不由 CMake 构建。请使用随包提供的独立 Python 构建说明，或直接使用与解释器版本匹配的预编译模块。

## 源码构建与版本资料

发布包的 `build/` 目录提供 CMake 和 Visual Studio 2022 两种 C++ 构建入口，二者均转接项目根目录的权威 CMake 定义，不包含旧 `ecflow` 工程或已剥离的 CEC 构建项。根目录 `发布日志.md` 汇总公开版本能力，`未来更新计划.md` 说明下一公开大版本的方向性计划。

## 数据包

程序包只带 13 个首方精简样例，便于立即验证命令、配置和接口。许可明确的完整实例集合以独立数据包提供，可覆盖安装到同一数据目录。

TSPLIB、QAPLIB、GK 等外部数据不在程序包内再分发；请按 [`数据包与外部数据.md`](数据包与外部数据.md) 从原站点下载，并使用教程中的转换工具接入。CEC 源码和数据也不随项目发布，教程提供通过通用 C++ 或 Python callable 接口连接外部 benchmark 的示例。

## 结果安全

默认运行会为同一优化器、问题和标签自动续号，避免覆盖旧结果。只有显式指定起始编号并启用替换选项时才允许受控覆写；替换过程会暂存新结果并在失败时恢复旧批次。
