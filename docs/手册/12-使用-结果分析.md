# 12 · 使用者篇 · 结果分析（ECAnalyzer）

跑完实验后，把**多算法 × 多问题**的结果日志汇总成一张**性能对比表**（含描述统计、显著性检验、排名、胜负、最优加粗），一键导出 Txt/Csv/LaTeX。
面向要**做实验对比**的使用者。配套可运行示例：`tutorial/4.log-analysis.cpp`。

> 统一入口只 `#include "ecflow.h"` **不含**分析层；用分析器需额外 `#include "ec-analyzer.h"`。

---

## 1. 数据从哪来：结果日志 `.rslt`

分析器**不重新跑优化**，它读优化器已经落盘的结果日志。所以前提是**跑实验时开了结果日志**：

```cpp
cb.name("psoA").tag("sphere").logging(/*result*/true);   // 开 .rslt
Optimizer* opt = cb.buildOptimizer();
opt->setProblem(&p);
opt->exe(20, seed);        // 跑 20 次重复 → 自动写 _0.rslt … _19.rslt
```

落盘路径固定为 `_log/<优化器名>/<问题名>/<优化器名>_<问题名>(<tag>)_<重复号>.rslt`。
分析器按同一规则回找，故 `addOptimizer(名, tag, 重复数)` 的 **名/tag/重复数必须与跑实验时一致**（`tag` 即 `cb.tag(...)`，不设则为时间戳、不可复现，**做对比实验务必显式设 tag**）。

---

## 2. 三阶段流水线

分析器把结果压成表格分三步（对应三组方法）：

| 阶段 | 方法 | 干什么 |
|---|---|---|
| **① 归约** | `reduceBy(...)` （**单选**） | 把**一次运行的解集**压成 1 个标量 |
| **② 聚合** | `addStatistic(...)` （**多列**） | 把 `重复数` 个标量聚合成表格列 |
| **③ 比较** | `addComparison(...)` | 算法间对比：显著性 / 排名 / 胜负 / 最优加粗 |

然后 `run()` 计算、`report(格式, 路径)` 导出。所有配置方法均**链式**（返回自身）。

---

## 3. 五个枚举

| 枚举 | 成员 | 用在 |
|---|---|---|
| `Stat` | `Mean, Variance, Std, Median, Mode, Smallest, Largest` | **①②通用**（跨用途：既可做单run归约，又可做跨run聚合） |
| `Indicator` | `HyperVolume, GD, IGD, PeakRatio` | **仅①**（解集质量指标，需参考点/前沿） |
| `Compare` | `Significance, Rank, WinTieLose, Best` | **仅③** |
| `Direction` | `MinIsBetter, MaxIsBetter` | ③的目标方向 |
| `Format` | `Txt, Csv, Latex`（`Excel/Word/Png` 暂未实现） | 输出格式 |

> 描述统计那组（`Stat`）是**同一枚举在①②两个阶段复用**：`reduceBy(Stat::Mean)` = 对解集求均值，`addStatistic(Stat::Mean)` = 对重复求均值——含义随方法不同。

---

## 4. 接口一览

```cpp
ECAnalyzer az;

// 参与者：算法 × 问题（重复数须与实验一致）
az.addOptimizer("psoA", "sphere", 20)
  .addOptimizer("psoB", "sphere", 20)
  .addProblem("sphere");                    // 或 addProblem({"p1","p2",...})

// ① 归约（二选一，单选）
az.reduceBy(ECAnalyzer::Stat::Mean, /*objIndex*/0);          // 描述式：对第 objIndex 个目标列
// az.reduceBy(ECAnalyzer::Indicator::IGD, refPerProblem);   // 指标式：见 §5

// ② 聚合列（可多次）
az.addStatistic(ECAnalyzer::Stat::Mean)
  .addStatistic(ECAnalyzer::Stat::Std)
  .addStatistic(ECAnalyzer::Stat::Smallest);

// ③ 比较（可多次）
az.addComparison(ECAnalyzer::Compare::Significance)                        // Mann-Whitney U，对基准算法出 p 值列
  .addComparison(ECAnalyzer::Compare::Rank,       ECAnalyzer::Stat::Mean, ECAnalyzer::Direction::MinIsBetter)
  .addComparison(ECAnalyzer::Compare::WinTieLose, ECAnalyzer::Stat::Mean, ECAnalyzer::Direction::MinIsBetter)
  .addComparison(ECAnalyzer::Compare::Best,       ECAnalyzer::Stat::Mean, ECAnalyzer::Direction::MinIsBetter);

// 计算 + 导出
az.run()
  .report(ECAnalyzer::Format::Txt,   "result")   // → _analysis/result.txt
  .report(ECAnalyzer::Format::Csv,   "result")
  .report(ECAnalyzer::Format::Latex, "result");  // → _analysis/result.tex
```

- **比较方法的 `on`**：指定拿哪一**聚合列**做比较（如按 `Stat::Mean` 列排名）；`Significance` 忽略 `on`（它直接比①的逐run标量）。
- **`Direction`**：`MinIsBetter`（默认，目标越小越好）/`MaxIsBetter`。
- **`report` 路径**：不含分隔符的名字自动落 `_analysis/<名>.<扩展>`；留空则 `_analysis/<归约名>(时间戳).<扩展>`。目录自动创建。

生成表大致长这样（`+/=/-` 为胜/平/负，最优列在 LaTeX 里 `\textbf` 加粗，`Rank` 为平均排名）：

```
        psoA                       psoB
        mean    std    smallest    p-value   mean    std    smallest   p-value
sphere  0.654   0.299  0.106       -         0.534   0.257  0.025      1.04
Rank    2.0/2                                1.0/2
+/=/-   -                                    0/1/0
```

## 5. 质量指标（多目标）

多目标实验用 `Indicator` 归约——从**一次运行的整个解集（Pareto 前沿）**算一个质量标量。参数按问题给（`refPerProblem[p]`）：

| 指标 | 含义 | `refPerProblem[p]` 约定 |
|---|---|---|
| `HyperVolume` | 支配超体积（越大越好） | **参考点**：长度 = 目标数（各目标一个上界/劣点） |
| `GD` | 世代距离（越小越好，收敛性） | **参考前沿**：行主序展平，长度 = 前沿点数 × 目标数 |
| `IGD` | 反向世代距离（越小越好，收敛+分布） | 同 GD |
| `PeakRatio` | 多峰命中率（越大越好，越接近 1 = 找到越多全局峰） | **4 标量**：`{f*, 峰数, ε, r}`，见 §5.1 |

```cpp
// 例：2 目标，HV 参考点 (5,5)
az.reduceBy(ECAnalyzer::Indicator::HyperVolume, { {5.0, 5.0} });

// 例：IGD 参考前沿（每问题一份，行主序 [f1,f2, f1,f2, ...]）
std::vector<double> front = { /* x0f1,x0f2,  x1f1,x1f2, ... */ };
az.reduceBy(ECAnalyzer::Indicator::IGD, { front });
```

前提：多目标实验用 `Multiobject` 档案（结果日志里存整条前沿）。指标结果再经 `addStatistic(Stat::Mean)` 对重复取均值。

### 5.1 多峰命中率 PeakRatio（标准 CEC niching 口径）

peakRatio 衡量多峰优化找到了多少个**全局峰**，工作在**决策/变量空间**：按适应度精度 ε 过滤到全局最优适应度 f\* → 按 niche 半径 r 去重 → 命中峰数 / 已知峰数。因此参数是 **4 个标量**（复用 `refPerProblem[p]`）：

```cpp
// refPerProblem[p] = { f*, 峰数, ε(适应度精度), r(niche 半径) }
az.reduceBy(ECAnalyzer::Indicator::PeakRatio, { { f_star, (double)peaks, 1e-1, rho } });
```

- **来源**：CEC2013 niching 基准直接给——`CEC2013 cec(fid); cec.get_fitness_goptima()`(f\*)、`get_no_goptima()`(峰数)、`get_rho()`(半径 r)；ε 取标准精度层（1e-1…1e-5）。
- **要求决策变量**：peakRatio 需解的 x 坐标，故实验必须开 `logging(true)`（full result → `.rslt` 为 ver 1.1，含决策变量块）；否则该指标返回空。
- 结果 clamp 到 [0,1]，再经 `addStatistic(Stat::Mean)` 对重复取均值。
- 用**多峰档案** `Multimodal`（`gArchive("Multimodal")`）收集多个峰。

## 6. 现状与边界

- **可用**：描述统计链（mean/std/median/mode/smallest/largest）· 全部比较（显著性/排名/胜负/最优）· HV/GD/IGD **及 PeakRatio** 指标 · Txt/Csv/Latex 输出。
- **暂未实现**：`Format::{Excel, Word, Png}` 输出格式。
- **单 TU 约定**：`ec-analyzer.h` 依赖的 metriclib 为非 inline 头内定义，**一个可执行只在一个编译单元包含它**（分析驱动通常就是单 main，不受限）。

---

## 7. 内部结构（供二次开发）

- `src/analyzer/ec-analyzer.h` —— `class ECAnalyzer`：`loadData`(读.rslt)→`_metric_cal`(①归约)→`_metric_analysis`(②聚合)→`_significant/_rank/_wl/_best_statistic`(③比较)→`_analysis_table`(拼字符串表)→`report`。
- `src/analyzer/out/out-txt.h`（Txt+Csv）、`out-latex.h`（LaTeX）—— `namespace FileOut` 的 `writeTableToXxx`，收 `vector<string>` 表格 + `bolds`。
- 指标/统计数学 = 第三方 **metriclib**（`v1/thirdparty/metriclib`，`namespace MetricLib`）整包引入。
