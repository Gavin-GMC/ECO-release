# 27 · 开发者篇 · 源码目录结构（组件在哪）

`src/` 全量目录 + 每处职责，标注**各注册组件族的落位**（新增组件放哪一目查）。
配合看：[20-架构与流程](20-开发-架构与流程.md)（层次/执行链）、[24-组件清单](24-开发-组件清单.md)（各组件）、[21](21-开发-内部组件.md)/[25](25-开发-扩展问题模块.md)（怎么加）。

> 统一入口：`src/ecflow.h`（= `problem.h` + `optimizer-builder.h` + `config-setter.h`）。

## 一、基础组件层 `src/`

```
basics/        ecflow-{basicfunc,constant,math,rand,sort,sys,time,eigen}.{h,cpp}
               └ 随机源(可复现)/数学/排序/系统/时间/常量/线代
calculator/    ecflow-calculator.h · ecflow-functor.hpp · func-calculator.cpp · tree-calculator.cpp
exprTree/      ExprTree.{h,cpp}
               └ muParserX 公式求值(目标/启发/表达式);见 [26-表达式语法]
solution/      solution.{h,cpp} · solution-decoder.{h,cpp}
               └ 候选解(result+fitness)+ 多变量布局解码
logger/        logger.hpp                      └ 两轴日志(系统/每优化器)
cp/            cp.h · solver.h                 └ 约束传播引擎(总入口)
  cp/compile/  parser.h · program.h            └ 表达式解析(算术+关系,无函数)+ 编译
  cp/core/     interval{,_set}.h · config.h · scalar_traits.h · small_vector.h
  cp/domain/   variable_domain.h
  cp/eval/     propagate.h · violation.h       └ 域传播 / 违反度
distribution/  distribution-{model,factory,type}.h
               └ 采样分布(Gaussian/Cauchy/Uniform/Histogram),供 EDA
multiobjective/ mo-util.h
               └ MOUtil:非支配排序/拥挤度/权重/邻域/Tchebycheff(纯工具、非注册组件;NSGA-II/MOEA-D 用,预留分析层复用 → 放 src 根)
```

## 二、问题模块 `src/problem/`（4 域 Define→compile→Manager）

```
core/          problem.h · problem-handle.h        └ Problem(持 4 Define)/ ProblemHandle(持 4 Manager+编排)
define/        {variable,objective,constrain,heuristic}-define.h · calc-spec.h   └ 4 域**描述**
manager/       {variable,objective,constraint,heuristic}-manager.h               └ 4 域**运行期引擎**(compile 产物)
variable/      variable.{h,cpp}                    └ 变量域实现
objective/     objective.{h,cpp} · comparer.hpp    └ 目标域 + 比较器(优先级分层+层内 Pareto 支配)
constrain/     ecflow-domain.h(域) · ecflow-cardinality.h(基数) · ecflow-accumulate.h(累积)
               ecflow-graph-constrain.h(图) · ecflow-constrain.h(cp 表达式/基类) · discrete_view.h
               └ 约束族实现;**加新约束**见 [25]
heuristic/     ecflow-inspiration.h                  └ 启发域实现
template/      problem-template.h · pt-{tsp,qap,mkp,numerical,mds,mis,cvrp,cflp,cpmp,fjsp,wfs,stp,sr}.h
               └ 13 个问题模板;**加新模板**见 [25]
```
> ⚠️ 约束**不走注册表**——`ConstrainDefine::compile()` 内 switch by `ConstrainKind`（见 [25 §1]）。

## 三、优化器模块 `src/optimizer/`

```
core/          registry.h(自注册表) · module-type.h(组件类别枚举) · parameter-template.h · ecflow-assert.h
               └ 组件注册/装配基础设施
individual/    individual.h · individual-{pbest,particle,setparticle,step,whale,firework}.h · individuals.h
               └ 个体基类 Individual + 特性(feature.h/feature-setvelocity.h)+ 聚合头 individuals.h(无子类/无 Registry<Individual>)
solution-op/   solution-initializer.h · solution-repairman.h
               └ Registry<SolutionRepaireman>(修复);初始化器**不走注册表**(OptimizerBuilder::Ibuild)
population/    individual-array.h · subpopulation.h · population.h   └ 个体集→子群→顶层聚合(核心)
subpopulation-constructer/  subpopulation-constructer.h              └ Registry<SubpopulationConstructer>
subpopulation-topology/     subpopulation-topology{,-basic}.h · neighbor-set.h  └ Registry<SubpopulationTopology>
subpopulation-manager/      subpopulation-manager{,-basic}.h         └ Registry<SubpopulationManager>
strategy/      learning-strategy.h(基类) · learning-strategies.h(聚合) · lstrategy-*.h
               └ Registry<LearningStrategy>;**加新策略**见 [21]
topology/      learning-topology.h(基类) · learning-graph.h · learning-topologies.h(聚合) · ltopology-*.h
               └ Registry<LearningTopology>;ltopology-neighborhood.h=MOEA/D 邻域
generator/     generator.h                         └ Registry<OffspringGenerator>
selector/      selector.h(基类) · select-{basic,immune,firework,rank-crowding,scalar-replace}.h  └ Registry<EnvirSelect>
evaluator/     evaluator{,-basic,-hash}.h          └ Registry<Evaluator>
terminator/    terminator.h                        └ 终止器(单一类,非注册族)
archive/       best-archive.h                      └ Registry<BestArchive>(Basic/Multiobject/Multimodal)
orchestrate/   optimize-component.h(O_Component) · optimize-workflow.h(O_Workflow) · component-wrappers.h
               optimizer-builder.h(装配) · optimizer.h(Optimizer)
               └ 流水线编排 + 装配 + 顶层优化器
config/        config-setter.h(ConfigBuilder fluent) · configure-list.h(FullConfig) · assert-matcher.h(装配校验)
               config-codec.h / config-codec-json.h(序列化)
               └ 配置构建/校验/序列化
```

## 四、注册组件族 ⇄ 目录 速查（加组件放哪）

| 组件族 | Registry | 基类文件 | 具体实现放这 | 聚合/注册接通点 |
|---|---|---|---|---|
| 学习策略 | `LearningStrategy` | strategy/learning-strategy.h | strategy/lstrategy-*.h | learning-strategies.h |
| 学习拓扑 | `LearningTopology` | topology/learning-topology.h | topology/ltopology-*.h | learning-topologies.h |
| 子代生成器 | `OffspringGenerator` | generator/generator.h | 同文件 | (同) |
| 环境选择 | `EnvirSelect` | selector/selector.h | selector/select-*.h | optimizer-builder.h + assert-matcher.h |
| 评估器 | `Evaluator` | evaluator/evaluator.h | evaluator/evaluator-*.h | (同) |
| 修复器 | `SolutionRepaireman` | solution-op/solution-repairman.h | 同文件 | (同) |
| 个体 | `Individual` | individual/individual.h | individual/individual-*.h | individuals.h |
| 档案 | `BestArchive` | archive/best-archive.h | 同文件 | (同) |
| 子群管理器 | `SubpopulationManager` | subpopulation-manager/subpopulation-manager.h | -basic.h | (同) |
| 子群构建器 | `SubpopulationConstructer` | subpopulation-constructer/subpopulation-constructer.h | 同文件 | (同) |
| 子群拓扑 | `SubpopulationTopology` | subpopulation-topology/subpopulation-topology.h | -basic.h | (同) |
| **不走注册表** | 初始化器 | solution-op/solution-initializer.h | 同文件 | OptimizerBuilder::Ibuild(硬编码) |
| **不走注册表** | 约束 | problem/constrain/*.h | 同目录 | ConstrainDefine::compile(switch by kind) |

> 加一个新算子的完整步骤见 [21](21-开发-内部组件.md)；加约束/模板见 [25](25-开发-扩展问题模块.md)。
