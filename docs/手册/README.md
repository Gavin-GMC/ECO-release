## 阅读路线

| 你是 | 从这里开始 |

| 想快速跑通一个优化 | [00-总览](00-总览.md) → `tutorial/0.problem.cpp`、`tutorial/1.optimizerconfig.cpp` |

| 要新增算子/扩展框架 | 开发者篇 · [架构与流程](20-开发-架构与流程.md)、[内部组件](21-开发-内部组件.md)、[组件清单](24-开发-组件清单.md) |

## tutorial 示例（参照稳定版 0–5 组织，适配当前 API）

| 文件 | 内容 | 状态 |
|---|---|---|
| `0.problem.cpp` | 问题定义全流程（变量/目标/约束/启发 + 编译 + 解评估/比较/约束传播/启发排序） | ✅ 本轮 |
| `1.optimizerconfig.cpp` | 单子群优化器配置与运行（ConfigBuilder → buildOptimizer → exe → 取最优） | ✅ 本轮 |
| `2.subpopulation.cpp` | 多段 workflow（交叉段+变异段）+ 子种群层访问 | ✅ 本轮 |
| `3.population-manager.cpp` | 多子群协作（异构子群 PSO+GA、NoInteraction 管理器） | ✅ 本轮 |
| `4.log-analysis.cpp` | 日志两轴（sys_logger + 每优化器结果/过程）+ **ECAnalyzer 分析**（读 `.rslt` → 对比表 → Txt/Csv/LaTeX，v4 迁移） | ✅ |
| `5.template.cpp` | 用问题模板端到端（PT_TSP 一键构造 → ACO 跑 → 取最优巡回） | ✅ 本轮 |
| `5.config-generate*.cpp` | 配置表批量生成（已有，见 tutorial 现有三文件） | ✅ 既有 |
